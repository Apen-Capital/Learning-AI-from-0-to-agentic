# Learning AI: from 0 to agentic

Study repository to prepare for the **CCAR-F** certification, which tests how to design and ship production applications with Claude: agentic architectures (Claude Agent SDK), MCP tools and resources, Claude Code workflows, structured output, and context management and reliability.

The target profile is a Solutions Architect who has built real applications with the Claude APIs, Agent SDK, Claude Code and MCP.

## Goal

Pass the exam, and build real hands-on understanding of each domain along the way. Two people study here, each with their own certification track.

## Exam snapshot

| | |
|---|---|
| Questions | 60, multiple choice and multiple response |
| Time | 120 minutes |
| Passing score | 720 |
| Scenarios | 4 drawn at random from a pool of 6 |
| Fee | USD 125 |
| Validity | 12 months from the date the credential is granted |
